Tentang Saya

Analitis, teliti, dan komunikatif

Saya lulusan S1 Informatika Telkom University (2022 – 2026) dengan pengalaman langsung dalam pengumpulan, pembersihan, dan visualisasi data melalui riset akademik, proyek dashboard Power BI, serta pelacakan data penjualan bisnis mahasiswa.

Saat ini saya mencari peran entry-level Data Analyst untuk memecahkan masalah bisnis nyata dengan pendekatan berbasis data.
